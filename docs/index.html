Installation Guide

How to install Privacy Shield in your browser.

Download the production package for your browser below. Takes less than sixty seconds with complete developer control and zero store telemetry.

Chromium Browsers

Google Chrome, Brave, Microsoft Edge, Arc, Opera

Permanent Installation
1

Click the button below to download the production build privacy-shield-chrome.zip.

2

Extract the ZIP archive into a permanent directory on your machine (for example, in your Documents or Applications folder).

3

Open this address in a new browser tab:

Browser Address chrome://extensions
Tip: Paste in the address bar using Ctrl+V or Cmd+V
4

Turn on Developer mode using the toggle switch located in the upper-right corner.

5

Click Load unpacked and select the extracted folder containing manifest.json.

6

Privacy Shield is active immediately. Pin the shield icon to your toolbar for quick settings access.

Permanent Status: Chromium saves loaded unpacked extensions directly into your user profile. The extension remains active across all browser restarts and system reboots.
Download for Chromium (.zip) Size: 290 KB : Production Build : Manifest V3

Mozilla Firefox

Firefox Desktop, Developer Edition, Nightly, Floorp, ESR

Permanent Installation
1

Click below to download the permanent add-on package privacy-shield-firefox.xpi.

2

Open the Firefox advanced configuration console:

Firefox Config about:config
Click "Accept the Risk and Continue" when prompted.
3

Search for this signature policy preference:

Preference Flag xpinstall.signatures.required
Double-click or click the toggle icon to set it to false. This authorizes permanent installation of offline add-on packages.
4

Navigate to the Add-ons and Themes manager:

Add-ons Manager about:addons
Click the gear icon and select "Install Add-on From File...", or drag and drop privacy-shield-firefox.xpi directly into the page.
5

Click Add when prompted. Privacy Shield is now permanently active.

Permanent Status: Unlike temporary debug sessions that disappear on close, this method permanently registers Privacy Shield with ID privacy-shield@apple-style.local, preserving your protection across all Firefox restarts.

Core Capabilities

Built with uncompromising privacy engineering.

Engineered from scratch without third-party libraries, analytics trackers, or remote code execution.

100% On-Device Processing

All text evaluations, regex scans, and checksum calculations happen locally on your processor. Zero network requests are permitted in the manifest.

0ms Pre-Paint Masking

Password inputs, card credentials, and OTP fields are masked via declarative CSS at document start. Eliminates single-frame visual leakage before compositor paints.

Universal Framework Immunity

Engineered with a dedicated DOM Reconciliation Guard in the main world. Fully compatible with Next.js App Router, React 18 SSR, Supabase, Vue 3, and Angular.

Native C++ TreeWalker Speed

Avoids recursive JavaScript DOM traversal by driving the browser engine's native TreeWalker API. Achieves 0.0% CPU consumption when pages are idle.

Luhn & Checksum Validation

Eliminates false positives by running ISO/IEC 7812 Luhn Mod 10 checksums on credit cards and ISO 7064 Mod 97-10 algorithms on international bank IBANs.

Security Guarantees

Verified zero telemetry and zero credential inspection.

Privacy Shield is client-side software designed to protect your sensitive browsing data without compromise.

Zero Telemetry or Analytics

No analytics engines, ping requests, or user tracking are included. Verified by automated security test suites.

Password Values Never Accessed

Password inputs are identified strictly by DOM input semantic attributes. The JavaScript engine never reads input.value.

Zero Remote Script Loading

All scripts and brand fonts (Geist and Manrope) are 100% locally bundled. No CDN connections are ever made.

Local-Only Preference Storage

All user configurations and website exclusions are persisted strictly inside your browser's local storage partition.
